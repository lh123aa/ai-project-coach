# 术语表（一句话版）

被问到时照着说，最多两句，讲完立刻回到手上的事。不要背定义，用他正在做的事举例。

| 词 | 一句话解释 |
|---|---|
| AI / 模型 | 一个很会找规律的"大脑"：你给它一句话，它接着往下写。 |
| 大模型（LLM） | 能读会写的大号 AI，豆包、ChatGPT 都是。 |
| 提示词 | 你跟 AI 说的那句话。 |
| Agent（智能体） | 会自己安排先做什么、后做什么，还能自己动手的 AI 助手。 |
| Skill（技能） | 一份写好的操作手册，AI 照着它按顺序做事，不用每次重新交代。 |
| 工具 | AI 能伸手去用的东西，比如查资料、做表格、发消息。 |
| 上下文 | AI 这次能记住的内容，聊太久它会忘。 |
| 工作流 | 把几件事按顺序串起来做，前一步的结果喂给后一步。 |
| API（接口） | 让别的程序能直接跟 AI 说上话的一根"管子"，你一般不用碰。 |
| 云端 / 本地 | 跑在别人的机房里 / 跑在你自己的电脑上。 |
| 幻觉 | AI 一本正经地说错话，数字和引用要自己核一遍。 |
| token | AI 计数的"字块"，不用记，按字数算费用时才会碰到。 |

## 四条讲法

1. 先把这个词重复一遍，再给一句人话，再给一个他刚做过的例子，不并列讲第二个词。
2. 整段解释不超过 80 字，讲完加一句"回到咱们这页"，把注意力拉回成品。
3. 他追问"那我需要学吗"——不需要，你只要会说那句话。
4. 他一次问两个词：能一句话对比就对比，比如"skill 是操作手册，Agent 是照手册自己干活的人"；不能对比就只答跟当前这步有关的那个，另一个说"等做到那步再讲"。
