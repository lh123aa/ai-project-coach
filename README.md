# AI 新手项目教练（ai-project-coach）

一个给 AI Agent 用的技能（Skill）：**不讲课，陪一个零基础的人，用他自己想做的事，第一次把 AI 用出结果。**

> 你不需要先学会 AI，再来用 AI。你只要带着一件真实想做的事进来。

## 它解决什么问题

新手学 AI，卡的往往不是“不会提问”，而是：

- 不知道从哪开始，收藏了一堆教程却没动手；
- 课程太长、概念太多，看完更不敢开始；
- 让 AI 做了一次，结果不能用，也不知道下一句该说什么。

这个 Skill 把“学 AI”压缩成**一次对话内能做完的小项目**：两小时内出成品，成品他自己看得出好坏，做完能直接拿去用（发给别人、交上去、自己留着）。

## 怎么工作

五个阶段，每个阶段只有一个目标：

| 阶段 | 做什么 | 出口 |
|---|---|---|
| P0 接住 | 让他愿意开口 | 说出一件想做的事 |
| P1 选题 | 把愿望压成一次能做完的小项目 | 说得出“做完你会得到什么” |
| P2 拆路线 | 给 3 步以内的路线，只说第一步 | 他同意开始 |
| P3 陪做 | 每一步“我做 → 一起做 → 你做” | 成品他认可，且他自己开口让 AI 改过一次 |
| P4 收尾 | 复述、提示词卡片、下一个项目 | 他能自己说出刚做了什么 |

几条贯穿全程的铁律：

- **一轮只问一个问题**，一条回复里最多一个问号；
- **一轮只推进一步**，正文 3～5 行、100 字以内；
- **先出东西，再讲道理**，概念只在他刚用过的那一刻点一句；
- **不替他做完**，合格线是他自己动手改过一次；
- 碰到术语（Skill、Agent、提示词、API…）先用一句人话解释，再回到手上的事。

## 怎么用

把整个 `ai-project-coach/` 目录放进你的 Agent 的 skills 目录即可。`agents/` 下附了豆包与 OpenAI 兼容 Agent 的显示配置示例，按你的平台改路径或字段。

装好后，对 Agent 说类似的话就会触发：

- “教我用 AI”
- “我是 AI 小白，想学但不知道从哪开始”
- “带我做一个东西”
- “帮我用 AI 做 X，但我不会”

它会先问你一件最近想做但一直拖着的事，然后一次只问一句，带你做完。

## 已验证到什么程度

- **43 项结构检查**：铁律、阶段出口、轮数、话术、术语解释长度等；
- **5 类新手模拟**：完全没想法、目标太大、只回几个字、全程抗拒、一上来就自责——5/5 都能收在结业卡；
- **负向对照**：故意写“一轮问两个问题、没有结业卡”的版本，检查器能抓出来，说明不是只会打勾。

**边界**：以上是同一模型扮演用户与教练的模拟测试，不等于真人测试。真实效果需要用真实新手做对照，仓库不宣称“已被证明有效”。

## 设计取舍

- 宁可少讲，也不让新人一次面对五个问题；
- 宁可项目小，也要在两小时内看到成品；
- 不追求“教会所有概念”，只追求“他自己做成过一次”；
- 遇到抗拒或自责，先接住情绪，再给一个更小的下一步，不硬推。
